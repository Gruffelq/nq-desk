Set your NQ Desk password

This runs only in your browser. Your password is never sent anywhere and never shown to Claude.

  1. Choose a strong password you don't use anywhere else (at least 12 characters).
  2. Click "Create keys" and copy the text that appears.
  3. Paste that text into the chat with Claude. It contains no password and can't be used without it.

Done. Copy this text and paste it into the chat with Claude.

If you lose the password, nobody can open the briefings, Claude included. You would then run this setup again.
